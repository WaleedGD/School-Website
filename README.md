# العلوم – الصف الرابع | Science – Grade 4

موقع تفاعلي لمراجعة مادة العلوم للصف الرابع الابتدائي (الجزء الأول).
An interactive website for reviewing Grade 4 Science (Part 1).

**إعداد المعلمة: دلال علي الرايقي – أكتوبر 2026**
**By Dalal Ali Al-Raiqi – October 2026**

## المحتوى | Contents

- 3 وحدات، 5 فصول، 12 درساً | 3 units, 5 chapters, 12 lessons
- لكل درس: ملخص، مفردات وتعريفات، خريطة مفاهيم، بطاقات فلاش، وأسئلة
  Each lesson: summary, vocabulary, concept map, flashcards, and questions
- اختبار فصلي لكل فصل، واختبار تراكمي لكل وحدة
  A chapter test per chapter and a cumulative test per unit
- وضع داكن، وحركات تفاعلية، ويعمل على الجوال والكمبيوتر
  Dark mode, animations, works on mobile and desktop



## النشر عبر GitHub Pages | Publishing

1. ارفع `index.html` و`LICENSE` و`README.md` إلى المستودع.
2. من Settings ثم Pages، اختر الفرع `main` والمجلد `/ (root)`.
3. انتظر دقائق ليظهر الرابط.
